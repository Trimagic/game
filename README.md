# С нуля! — Telegram Mini App

Основа игры на 11 глав: **React + TypeScript + Vite + Phaser**, **Cloudflare Workers Static Assets**, прогресс в **D1**.

Первый этап: комикс из четырёх кадров про решение заняться собой и велозаезд на 500 метров (40 секунд). Три полосы, бабушки, дети и банановая кожура, три ошибки до перезапуска, пауза и повтор. Управление стрелками / A D, кнопками или касанием краёв дорожки. Реализованы все 11 глав.

Иллюстрации находятся в `public/art/`; промпты и происхождение — `docs/art-prompts.md`.

## Локальный запуск

Требуется Node.js 22.12+ (рекомендуется 24).

```sh
npm ci
npm run db:local
npm run dev
```

В браузере доступен деморежим с отдельным localStorage. В Telegram используется только серверный прогресс; ошибки API не подменяются локальным сохранением.

Для проверки Telegram локально создай `.dev.vars` (он исключён из Git):

```dotenv
BOT_TOKEN=your_bot_token
```

Нужен HTTPS-адрес, доступный Telegram, например через туннель. Токен бота никогда не помещать в `VITE_*`, клиентский код или Git.

## Cloudflare Workers

```sh
npx wrangler login
npx wrangler d1 create game-progress
```

Замени нулевой `database_id` в `wrangler.jsonc` на ID созданной базы. Нулевой ID — заглушка для локальной разработки.

```sh
npm run db:remote
npx wrangler secret put BOT_TOKEN
npm run deploy
```

В BotFather укажи HTTPS-адрес Worker для Mini App / кнопки меню бота. Для Git-интеграции Cloudflare Workers: build command `npm run build`, deploy command `npx wrangler deploy`. До первого деплоя настрой D1 и секрет.

## Проверки

```sh
npm test
npm run build
npm run test:integration
```

Интеграционные проверки запускают настоящий Workers runtime с изолированной D1: авторизация, порядок глав, повторные и конкурентные записи, изоляция пользователей.

## Структура

- `src/App.tsx` — карта, комикс, переходы и сохранение.
- `src/Game.tsx` — Phaser, загружается при входе в мини-игру и уничтожается при выходе.
- `src/telegram.ts` — Telegram API и отдельный браузерный деморежим.
- `worker/auth.ts` — HMAC-проверка initData, срок действия 24 часа.
- `worker/index.ts` — GET/POST `/api/progress`; ID пользователя берётся из проверенной подписи.
- `migrations/` — схема D1.

Прогресс хранится как количество последовательно завершённых глав. Повторная запись идемпотентна; атомарное обновление не позволяет пропустить главу или уменьшить прогресс. Клиент сообщает о победе сам: это сохранение прохождения, а не античит для призов или соревновательных рейтингов.

Авторизация с истёкшим initData требует повторного открытия приложения. Облачное развёртывание требует доступа к аккаунту Cloudflare и токена Telegram-бота.

## Этап 02 — Заплыв с сюрпризом

Открывается после велозаезда: четыре кадра комикса, правила, справка со ссылками на ВОЗ/CDC, 45-секундный заплыв. Удерживайте экран, кнопку, пробел или стрелку вверх; отпускание опускает героя. Три столкновения завершают попытку. С 30-й секунды появляется Какун, выпускающий четыре волны препятствий со свободным проходом. Есть пауза, повтор и сохранение второго этапа. Число 0,14 г в справке — оценка остатков на коже из CDC, не статистика ВОЗ или измеренное содержание бассейна.

Промпты иллюстраций и источники: docs/chapter-02-art-prompts.md. Проверка модели заплыва: npm test.

## Этап 03 — Правильная закупка

Открывается после бассейна. Активная версия — движущаяся лента на Phaser (`src/shop/ShopScene.ts`, `src/shop/belt.ts`). За 60 секунд нужно собрать пять продуктов за 35 монет. Товары повторяются, лента ускоряется на 30-й и 45-й секундах. Два заряда стоп-ленты дают по 3 секунды остановки товаров без остановки часов. Новые продукты по списку дают серии и очки, лишние сбрасывают серию. Покупки можно нажимать или перетаскивать; лишнее возвращается нажатием в корзине. Касса открывается с 45-й секунды, на 60-й готовая корзина оплачивается автоматически. Прежняя модель отделов `market.ts` больше не используется активной игрой.

Модель и баланс: src/shop/model.ts; интерфейс: src/shop/ShopGame.tsx. Проверка в изолированной локальной сцене без изменения прогресса: /tests/shop-preview.html при запущенном npm run dev. Этот HTML не входит в production-сборку. Промпты: docs/chapter-03-art-prompts.md.

## Этап 04 — Диетический ужин

Открывается после закупки. Новый комикс и три части игры: шесть разрезов по направляющим (мышь, касание или кнопка), 42 секунды у двух конфорок и сервировка. Пять действий на плите имеют видимые временные окна; три пропуска завершают попытку. Звонок мамы на 26-й секунде отклоняется кнопкой или заканчивается на 31-й, оставляя время снять гарнир. Есть пауза, автоматическая пауза при потере фокуса, повтор и сохранение четвёртого этапа. Время готовки условное.

Логика: src/cook/model.ts. Проверки: tests/cook.test.ts. Отдельный локальный запуск без изменения прогресса: /tests/cook-preview.html. Комикс и спрайты: public/art/chapter-04-comic.png и public/art/chapter-04-food.png. Полные промпты встроенного генератора: docs/chapter-04-art-prompts.md.


## Глава 05 — Качай в ритм

Ритм-игра на 56 секунд: гантели (90 BPM), удержания с независимыми нажатиями другой рукой (108 BPM), финальные двойные ноты и ускорение (126 BPM). Управление: A/D, стрелки или две сенсорные кнопки. Победа: дойти до конца с точностью от 65%; промахи отнимают силы, попадания восстанавливают. Есть комбо, синтезированный звуковой ритм, выключение звука, пауза и автоматическая пауза при потере фокуса. Прогресс главы 5 сохраняется существующим последовательным API.

Локальное превью без изменения прогресса: http://127.0.0.1:5173/tests/gym-preview. Комикс: public/art/chapter-05-comic.png; промпт: docs/chapter-05-art-prompts.md. Модель и тесты: src/gym/model.ts и tests/gym.test.ts.


## Архивный прототип — Лифт не для нас

Вертикальная прыгалка до десятого этажа: автоматические прыжки, удержание стрелок/A/D или сенсорных кнопок, узкие и подвижные площадки, необязательные пружины-срезы, пакеты, открывающиеся двери и кот. Контрольные точки на 4-м и 7-м этажах с передышкой; после падения доступны неограниченные повторы от последней точки. Потеря фокуса ставит игру на паузу. Камера идёт вверх, финал засчитывается при приземлении на площадку квартиры.

Превью: http://127.0.0.1:5173/tests/stairs-preview (не меняет сохранённый прогресс). В основной игре глава открывается после спортзала и сохраняется через существующий API. Комикс и спрайты: public/art/chapter-06-*.png; промпты: docs/chapter-06-art-prompts.md. Детерминированная физика: src/stairs/model.ts; тесты проверяют полный обычный маршрут с препятствиями, достижимость площадок, пружины, контрольные точки и финиш.


## Глава 06 — Ещё пять минут

Текущая шестая глава заменяет лестницу: ночной лабиринт по мотивам Pac-Man. Нужно собрать 600 очков (60 искр по 10) и добраться до кровати наверху. Четыре преследователя — уведомления, YouTube, кино и игры — выходят по очереди, ускоряются после 300 очков и в финале. Четыре луны дают 7 секунд «Не беспокоить»: экраны убегают, столкновение отправляет их домой на 4 секунды. Без бонуса столкновение отнимает жизнь, но сохраняет очки. Три столкновения — проигрыш.

Управление: стрелки, WASD, кнопки или свайпы; направление запоминается до ближайшего доступного поворота. Есть пауза и автопауза при уходе из окна. Новая победа сохраняет главу 6 существующим API. Сохранённый прогресс прежней версии не сбрасывается.

Превью: http://127.0.0.1:5173/tests/sleep-preview. Старый прототип лестницы сохранён отдельно, но в карте глав используется сон. Комикс: public/art/chapter-06-sleep-comic.png, промпт: docs/chapter-06-sleep-art-prompts.md.


## Глава 07 — Утренний бег

Раннер с видом сбоку по мотивам динозаврика Chrome. Раунд 60 секунд, условная дистанция 1000 м. Автоматический бег ускоряется; пробел/↑/W или кнопка выполняют прыжок, удержание ↓/S или кнопки — пригибание. Лужи, пакеты и самокат нужно перепрыгивать, низкие ветки — проходить пригнувшись. Финал добавляет пары пакетов и чередование действий. Три сердца, защита после удара, пауза и автопауза при потере фокуса.

Глава открывается после сна и сохраняется существующим API. Восьмая глава запланирована как «Всё по расписанию». Локальное превью без изменения прогресса: http://127.0.0.1:5173/tests/run-preview. Комикс и спрайты: public/art/chapter-07-*.png; промпты: docs/chapter-07-art-prompts.md. Тесты проверяют полное прохождение без урона, прыжки, пригибание, столкновения и финиш.

## Глава 08 — Всё по расписанию

Три дня головоломки: карточки длительности, временные окна, защищённый сон и обязательный отдых. Среда добавляет фиксированную работу и дорогу; пятница — доставку и дополнительный час совещания после проверки плана. Конфликтующие дела возвращаются в карточки. Можно выбирать карточку и час начала либо перетаскивать карточки мышью. Без таймера и штрафов.

Локальное превью: `/tests/schedule-preview`. Оно не меняет сохранённый прогресс и не входит в production-сборку. В основной игре глава открывается после главы 7. Модель и проверки решаемости: `src/schedule/model.ts`, `tests/schedule.test.ts`. Комикс: `public/art/chapter-08-comic.png`; промпт: `docs/chapter-08-art-prompts.md`.

### Движок главы 06

«Ещё пять минут» использует Phaser: `src/sleep/SleepScene.ts` отвечает за Canvas/WebGL, игровой цикл, клавиатуру, свайпы и анимации. React в `SleepGame.tsx` показывает HUD, экран паузы и кнопки управления. Проверяемая клеточная логика остаётся в `src/sleep/model.ts`; Arcade Physics не нужна для дискретного лабиринта. Phaser загружается лениво, экземпляр уничтожается при выходе.

### Phaser: закупка и ужин

Главы 03 и 04 используют общий React-контейнер `src/arcade/ArcadeGame.tsx` и лениво загружаемые Phaser-сцены. React отвечает за паузу, результат и доступные кнопки; Phaser — за изображения, жесты, игровой цикл и анимации. У кухни сохранены шесть разрезов, пять действий на двух конфорках, звонок и подача. Новая модель `src/cook/precision.ts` добавляет бегунок, зелёную зону, серии и очки мастерства. На тарелке три подписанные зоны для перетаскивания.

За разрез начисляется 5 очков, действие в зелёной зоне — 20, в её центре — 30, часть блюда — 10. Три звезды за 160 очков, две за 110. Оценка раунда показывается на результате; общий API по-прежнему сохраняет прохождение главы. Превью: `/tests/shop-preview` и `/tests/cook-preview`. Тесты: `tests/market.test.ts`, `tests/cook-precision.test.ts`.

### Спортзал — Phaser
Глава 5 использует GymScene: две дорожки ритма, анимированный герой, три подхода 90/108/126 BPM, длинные и двойные ноты. Ввод: A/D, стрелки либо две кнопки на canvas; удержания поддерживают два касания. Пробел — однократное «Второе дыхание» (+25 сил после серии из 8), M — метроном. При паузе время останавливается, длинную ноту нужно зажать снова. Предпросмотр: /tests/gym-preview. Проверки модели: tests/gym.test.ts.


### Утренний бег — Phaser
Глава 7 теперь использует RunScene: анимированный бегун, многослойный парк, прыжки, пригибание, дорожные барьеры и растущая скорость. Искры собираются в прыжке или при пригибании под веткой. Пять искр тратятся на 3 секунды фокуса (F), замедляющего всю симуляцию до 55% скорости. Очки начисляются за искры и серии препятствий без столкновений. Предпросмотр: /tests/run-preview. Модель движения и столкновений: src/run/model.ts; очки и фокус: src/run/round.ts. Проверки: tests/run.test.ts, tests/run-round.test.ts.


### Распорядок дня — тетрис на Phaser
Глава 8 заменена тетрисом дел: поле 10×16, семь фигур в перемешиваемых наборах, предпросмотр следующей фигуры, контур приземления, повороты у стен и задержка фиксации. Победа после 7 линий, поражение при заблокированном появлении фигуры. Темп растёт с прогрессом; C один раз заменяет текущую фигуру следующей. Стрелки — движение/поворот, пробел — сброс; на телефоне кнопки. Комикс сохранён с обновлёнными репликами. Предпросмотр /tests/schedule-preview. Логика: src/schedule/tetris.ts; сцена: src/schedule/ScheduleScene.ts; проверки: tests/tetris.test.ts. Старый планировщик в model.ts оставлен как неиспользуемый прототип.


### Глава 09 — Битва за пульт
Переход «40 лет спустя», четыре кадра вступления, 40 секунд арены Phaser с орешками, диванами и соперниками. Затем бабушка подходит сзади, оглушает героя киркой в комиксовой вспышке и забирает пульт. Четыре финальных кадра ведут к сохранению главы: сюжетное поражение считается прохождением. Открывается после главы 8 без спойлера на карте. Превью: /tests/remote-preview. Модель: src/remote/model.ts; тесты: tests/remote.test.ts; промпт иллюстраций: docs/chapter-09-art-prompts.md.

В главе 09 контакт с неоглушённым соперником немедленно завершает раунд поражением. «Попробовать снова» запускает чистый раунд с таймером 40 секунд. Финальная сцена с бабушкой доступна только после выживания до конца таймера; обычное поражение главу не завершает.

### Глава 10 — Операция «Обед»
Стелс на Phaser: столовая, коридор и вестибюль. Персонал движется по патрульным маршрутам; жёлтые клетки показывают обзор с учётом стен. Подозрение нарастает на виду и спадает в укрытии. Столкновение или полная шкала — поражение и повтор всего маршрута. Между локациями игра ждёт подтверждения. Последняя дверь запускает сюжетный перехват доставки и четыре кадра финала с брокколи и водой; завершение комикса сохраняет главу. Вступление — четыре кадра мечты, обеда и заказа.

Управление: WASD/стрелки, удержание экранной крестовины или доступные кнопки шагов; Enter — следующая локация. Локальное превью /tests/delivery-preview не меняет прогресс. Модель: src/delivery/model.ts; сцена: src/delivery/DeliveryScene.ts. Тесты находят реальные безопасные маршруты во всех трёх локациях с активными патрулями. Иллюстрации: public/art/chapter-10-comic.png; полный промпт встроенного ImageGen: docs/chapter-10-art-prompts.md.

Всего теперь 11 глав. Миграция migrations/0002_eleven_chapters.sql расширяет ограничение D1, копируя существующие данные и даты. Перед публикацией новой версии применить npm run db:remote, локально — npm run db:local. Интеграционный тест проверяет сохранность старых записей и последовательное прохождение всех 11 глав. Глава 11 подключена после завершения главы 10.

### Глава 11 — Ночной маршрут

После финала главы 11 открывается эпилог «Последний поворот»: 12 кадров, разговор с врачом, пробуждение после падения с велосипеда, кнопка «Сделать правильный выбор» и сатирическая развязка. Поздравление появляется после последнего кадра; сохранение главы вызывается кнопкой завершения истории. Отдельное превью без изменения прогресса: `/tests/epilogue-preview`. Компонент: `src/night/Epilogue.tsx`.
Боковой платформер Phaser с ручным движением, прыжком переменной высоты, небольшим запасом времени после края платформы и буфером прыжка. Тумбочки, два ремонтных разрыва пола, мокрые участки и движущаяся тележка. Терпение расходуется со временем; столкновение снимает 18, лунный жетон возвращает 12. Падение или пустая шкала — повтор. У двери запускается сюжетный проигрыш: туалет закрыт, эпизод с цветком за кадром и медсестра с подгузниками. Вступление и финал — по четыре кадра. Завершение финала сохраняет главу 11.

Превью: /tests/night-preview. Стрелки / A D — ходьба; пробел / вверх / W — прыжок. На телефоне удерживай движение и прыжок одновременно. Модель: src/night/model.ts; сцена: src/night/NightScene.ts; проверки: tests/night.test.ts, включая полное прохождение без отключения препятствий. Комикс: public/art/chapter-11-comic.png.
