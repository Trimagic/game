# Happy Birthday · описание и приветствие

Публичный бот: https://t.me/magic_happy_birthday_bot

Тексты профиля и сообщения: `worker/bot-copy.ts`. Короткое описание отображается в профиле и при пересылке ссылки; полное — перед первым запуском. `/start` и `/help` в личном чате присылают обложку, HTML-подпись и кнопку Mini App. Будущие задания не раскрываются.

Webhook: `/api/telegram/webhook`, только POST от Telegram с проверенным секретным заголовком. Секрет HMAC выводится из BOT_TOKEN; токен и данные чатов не записываются в логи. D1 `bot_updates` хранит только номер обновления, состояние отправки и время. Атомарная аренда защищает от одновременных повторов; записи об успешных отправках удаляются через семь дней. При временной ошибке Telegram может повторить доставку. Если обложка недоступна, остаются текст и кнопка. Ошибки 403 подтверждаются без повторов.

Публикация:

1. `npm run db:remote` — добавить таблицу, не затрагивая прогресс игры.
2. `npm run deploy`.
3. `node --experimental-strip-types scripts/configure-bot-profile.mjs --apply` — обновить описания и команды, установить webhook, проверить настройки. Скрипт проверяет имя бота и не заменяет чужой webhook.

Проверка: `node --experimental-strip-types --test tests/bot.test.ts`; после сборки — `node --experimental-strip-types tests/bot.integration.mjs` и `node tests/progress.integration.mjs`. Проверяются авторизация webhook, реальная D1, дубликаты, одновременная доставка, повтор после сбоя и сохранение 11 глав. Тесты не отправляют сообщения в Telegram.

`tests/bot-welcome-preview.html` — визуальный макет, использующий те же тексты и обложку; не входит в production-сборку. Скриншот `docs/bot-welcome-preview.jpg` — предпросмотр, а не снимок отправленного сообщения Telegram.
