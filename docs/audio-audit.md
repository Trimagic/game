# Проверка звука во всех 11 играх

Музыка синтезируется Web Audio. Десять фоновых аранжировок имеют мелодию, бас, гармонию и тихую перкуссию. Спортзал играет от часов своей ритм-карты, без параллельной фоновой петли.

| Глава | Музыка | Звуки основных событий |
|---|---|---|
| 1 · Велосипед | 116 BPM, бодрая | Перестроение, звонок, предупреждение, трамплин, приземление, лужа, ускорение, предметы, удар |
| 2 · Бассейн | 108 BPM, упругая | Гребок, рывок, щит, столкновение, кольцо, очки |
| 3 · Магазин | 122 BPM, суетливая | Товар, ошибка, акция, вор, тяжёлый предмет, завершение списка, последние секунды |
| 4 · Кухня | 112 BPM, игривая | Нарезка, плита, телефон, готовность, приправа, вспышка, тушение, подача |
| 5 · Спортзал | Темп трёх подходов ритм-карты | Отсчёт, попадания, промах, серия, второе дыхание, бонусный подход |
| 6 · Сон | 78 BPM, мягкая | Поворот, искры, потеря жизни, бонус, зевок, рост сложности |
| 7 · Бег | 142 BPM, энергичная | Прыжок, приседание, приземление, предметы, искры, чистый проход, удар |
| 8 · Расписание | 104 BPM, ровная | Сдвиг, поворот, сброс, перенос, штамп, постановка, линия, дедлайн |
| 9 · Пульт | 116 BPM, комичная погоня | Бросок, попадание, тележка, предупреждение, ковёр, сюжетный финал |
| 10 · Доставка | 98 BPM, тихий стелс | Шаг, укрытие, отвлечение, тревога, переход локации |
| 11 · Ночной маршрут | 94 BPM, осторожная | Прыжки, приземления, предметы, чекпоинт, ловушки, пар, скрип, погоня, низкое терпение |

Во всех играх есть общий переключатель звука, сохранение выбора, сигналы победы/поражения. Сюжетное завершение звучит нейтральным звонком. Именинная мелодия финала сохранена.

Изменения движка: планирование нот по аудиочасам, без накопления отставания после медленного кадра; отмена запланированных голосов при паузе, отключении звука и смене темы; восстановление после возвращения фокуса при следующем действии игрока.

Проверки: 225 автоматических тестов прошли. В браузере OfflineAudioContext отрендерил все 11 тем: RMS 0.0038–0.0066, peak 0.045–0.112 при шкале ±1. Это подтверждает наличие сигнала без клиппинга, а не субъективное прослушивание.

Локальный стенд: `/tests/audio-preview.html` — переключение всех тем, 21 эффект, победа, поражение, пауза и проверка реального Web Audio. Не входит в сборку сайта.


Главное меню: отдельная светлая тема 118 BPM с синкопированным ритмом. Меню использует тот же сохранённый переключатель звука. Отдельная кнопка запускает музыку первым нажатием, работает с Enter/Space, показывает состояние и эквалайзер. При входе в главу музыка меню останавливается; при возврате восстанавливается, если звук включён. В фоне воспроизведение приостанавливается. Проверены управление кнопкой на телефоне и аудиотесты переходов/выключения.
